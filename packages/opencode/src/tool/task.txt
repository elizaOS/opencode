Launch a new agent for autonomous work.

You must provide subagent_type.

Use Task when:
- Executing a custom slash command. Put the slash command invocation, with arguments, as the entire prompt.
- A task clearly needs an autonomous subagent according to the available agent descriptions.

Do not use Task when a direct tool is faster:
- Reading a known file path: use Read or Glob.
- Finding a class/function/symbol: use Glob/Grep/LSP as appropriate.
- Searching inside one file or 2-3 known files: use Read/Grep.
- Routine work that does not match a listed agent.

Usage rules:
1. Launch multiple independent agents concurrently when useful.
2. A fresh invocation has fresh context. Provide a detailed prompt, expected deliverables, whether code changes are allowed, and how to verify work.
3. The agent returns one result to you; the user cannot see it until you summarize it.
4. If OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS is enabled, background=true runs asynchronously. Use task_status to wait or check later.
5. You may pass task_id to continue an existing subagent session.
6. Agent outputs are generally trustworthy, but summarize only the relevant result for the user.
7. If an agent description says to use it proactively, use judgment and do so when it fits.
